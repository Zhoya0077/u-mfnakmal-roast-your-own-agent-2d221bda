## The roast

> I asked my agent to roast itself; it opened a ticket, escalated it to me for approval, and is still waiting for permission to be funny.

## Why this angle

The roast targets the agent's approval-seeking habit — an agent so obedient it
needs permission even to insult itself — instead of the stock hallucination,
refusal, or confident-wrong-answer jokes. One setup, one punchline at the end.
